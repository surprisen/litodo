# LiTodo 개인정보처리방침 (Privacy Policy)

**시행일: 2026년 11월 8일**

한국어 · [English](en/)

LiTodo(이하 "앱")을 만들고 운영하는 개인 개발자 남기훈(이하 "운영자")은 사용자의 개인정보와 데이터를 소중히 여기며, 「개인정보 보호법」 등 관련 법령과 Google Play 개발자 정책, Apple App Store 심사 지침을 준수합니다. 본 방침은 LiTodo Android 앱, iOS 앱(위젯 포함), macOS 앱(위젯 포함), Windows 데스크톱 앱과 LiTodo 웹사이트가 사용자의 정보를 어떻게 처리하고 보호하는지 설명합니다.

---

## 1. 처리하는 정보

LiTodo는 회원가입을 받지 않고, 광고 추적 식별자를 수집하지 않으며, 사용 통계·분석 도구와 광고를 사용하지 않습니다. 운영자의 서버에는 사용자의 할 일이나 계정 정보를 저장하지 않습니다.

### 1) 기기에 저장되는 데이터 (필수)
* **항목**: 사용자가 작성한 할 일 내용, 완료 일시, 알림·위젯·테마 등 앱 설정값, 기기별 무작위 식별자(동기화용, 아래 3번 참조)
* **보관 장소**: 사용자의 기기 내부 저장소 (Android: 앱 전용 데이터베이스, iOS·macOS: 앱과 LiTodo 위젯만 함께 쓰는 앱 전용 공유 저장소, Windows: `%LOCALAPPDATA%\LiTodo` 폴더)
* **외부 전송**: 클라우드 동기화를 켜지 않으면 앱이 할 일 데이터를 기기 밖으로 보내지 않습니다. 다만 사용자가 켠 운영체제의 기기 백업·이전 기능(Android의 Google 백업과 기기 간 이전, iPhone의 iCloud 백업과 기기 이전 등)에는 할 일과 설정이 포함될 수 있습니다. Google 로그인 정보는 이런 백업·이전에 포함되지 않습니다.
* **기기 안 백업**: 실수로 지우거나 동기화로 사라진 할 일을 되살릴 수 있도록, 앱이 할 일과 삭제 기록의 사본을 기기의 앱 전용 공간에 자동으로 남깁니다. 최근 30일 동안은 할 일을 바꾼 날마다 하나와 한꺼번에 지우거나 바꾸는 작업(완료 비우기, 다른 기기에서 지운 할 일의 동기화, 앱 업데이트 등) 직전마다 남기고, 그 뒤에는 1년까지 달마다 하나만 남긴 뒤 지웁니다. 전체 크기가 정해진 한도를 넘으면 오래된 것부터 지웁니다. 다만 작업 종류마다 가장 최근 백업 하나는 되살릴 수 있도록 기간과 관계없이 남깁니다(같은 작업을 다시 하면 새 백업으로 바뀝니다). 백업은 외부로 전송하지 않으며, 운영체제의 기기 백업·이전에도 포함하지 않습니다.
* **진단 기록**: 문제가 생겼을 때 원인을 찾을 수 있도록, 앱이 동기화·동기화 신호·계정 연결·오류 같은 동작 기록을 기기의 앱 전용 공간에 30일 동안(전체 약 2MB까지) 남깁니다. 할 일 내용, 계정 이메일, 로그인 정보는 남기지 않습니다. 진단 기록은 외부로 전송하지 않고 운영체제의 기기 백업·이전에도 포함하지 않으며, 아래 6)의 문제 신고에서 사용자가 직접 메일로 보낼 때만 기기 밖으로 나갑니다.
* **Siri·단축어 (iOS)**: "LiTodo에 추가"로 할 일을 추가할 때 음성 인식은 Apple이 처리하며, 앱은 인식된 할 일 텍스트만 받아 기기에 저장합니다.

### 2) Google 계정 연결 및 클라우드 동기화 (선택)
사용자가 설정에서 Google 계정을 연결한 경우에만 처리합니다.
* **항목과 보관 장소**:
  * Google 계정 이메일 주소: 기기의 앱 설정에 보관합니다. 연결을 해제해도, 나중에 다른 계정에 연결할 때 기존 할 일을 지킬지 판단하려고 "이전 계정"으로 기기에 남으며, 앱을 삭제하면 함께 지워집니다.
  * 할 일 동기화 파일(`todonotification_backup.json`. 할 일과 마지막으로 올린 기기의 무작위 식별자를 담습니다)과 기기 접속 기록(기기마다 내용 없는 파일 하나. 파일 이름에 기기별 무작위 식별자와 기기 종류(Android, iOS, Windows, macOS)를 담고, 파일 수정 시각을 마지막 접속 시각으로 씁니다): 사용자 본인의 Google Drive 안에 있는 앱 전용 숨김 폴더(`appDataFolder`)에 보관합니다.
* **목적**: 여러 기기 간 할 일 동기화 및 백업. 기기 접속 기록은 같은 계정에 최근 사용한 다른 기기가 없을 때 실시간 동기화 신호(아래 3번)를 보내지 않기 위해서만 씁니다
* **접근 범위**: 앱은 사용자의 Drive 전체에 접근할 수 없으며, LiTodo가 만든 앱 전용 폴더에만 접근합니다. 요청하는 Google 권한은 앱 전용 폴더 접근(`https://www.googleapis.com/auth/drive.appdata`)과 로그인·계정 이메일 확인(`openid`, `email`)뿐입니다.
* **Google API 사용자 데이터 정책**: LiTodo가 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따릅니다. 이 정보는 할 일 동기화에만 쓰며, 광고에 쓰거나 판매하거나 제3자에게 넘기지 않고, 일반화된 인공지능·머신러닝 모델을 만들거나 개선하거나 학습시키는 데 쓰지 않습니다.
* **로그인 정보**: Google 로그인 인증 정보는 기기 안에만 보관됩니다 (Android: Google Play 서비스, iOS: 기기 키체인. 앱을 열지 않고 위젯·Siri에서 바로 동기화할 수 있도록 앱과 LiTodo 위젯이 함께 쓰며, 이 기기에서만 사용되고 백업이나 기기 이전으로 옮겨지지 않습니다. macOS: 기기 키체인, 앱만 사용. Windows: `%LOCALAPPDATA%\LiTodo\GoogleAuth` 폴더).

### 3) 실시간 동기화 알림
한 기기에서 할 일이 바뀌면 다른 기기가 바로 최신 내용을 받을 수 있도록 알림 신호를 보냅니다. **이 신호에는 할 일 내용이 포함되지 않습니다.** 신호는 Google 계정을 연결한 뒤에만 보내고 받으며, 아래 푸시 서비스 등록도 계정을 연결할 때 하고 연결을 해제하면 지웁니다. 계정을 연결하지 않으면 이 항목의 처리는 일어나지 않습니다.
* **LiTodo 중계 서버 (Cloudflare Workers에서 운영)**
  * 전송 항목: 계정 이메일로 만든 해시 값(이메일 원문 아님), 기기별 무작위 식별자
  * 목적: 같은 계정의 다른 기기로 동기화 신호 전달
  * 보관: 저장하지 않습니다. 짧은 시간 내 중복 발송을 막기 위해 해시 값과 요청 시각을 수 초간 메모리에만 유지합니다. 요청 처리 과정에서 Cloudflare가 네트워크 정보(IP 주소 등)를 처리할 수 있습니다.
* **Firebase Cloud Messaging (Google, Android·iOS 앱)**
  * 처리 항목: 푸시 전달을 위한 기기 등록 토큰(Firebase 설치 ID. 계정을 연결할 때 만들고, 연결을 해제하면 토큰과 설치 ID를 지웁니다), 위 해시 값으로 만든 구독 주제(계정을 연결한 뒤에 만듭니다). iOS에서는 Apple 푸시 알림 서비스(APNs)의 기기 토큰도 함께 처리합니다.
  * 함께 처리되는 기기 정보: 등록할 때 Firebase가 기기 모델, OS 버전, 앱 버전, 언어·시간대 같은 기기 정보를 함께 받습니다. Google은 이 정보를 푸시 전달과 플랫폼별 사용 현황 파악에 쓰며 사용자나 기기 식별자와 연결하지 않는다고 밝힙니다.
  * 목적: 중계 서버의 신호를 Android 기기와 iOS 기기(앱이 화면에 없을 때)에 전달. Android에서는 아무것도 표시하지 않습니다. iOS에서는 신호가 소리·진동 없는 알림으로 도착하고, 기기 안에서 동기화한 뒤 그 알림의 내용을 기기에 저장된 할 일로 채웁니다(신호 자체에는 할 일 내용이 없습니다). iOS 알림을 허용하지 않았다면 아무것도 표시하지 않고 동기화만 합니다.
* **Apple 푸시 알림 서비스 (Apple, iOS 앱)**
  * 처리 항목: 위 신호(할 일 내용 없음)와 APNs 기기 토큰
  * 목적: Firebase Cloud Messaging이 보낸 신호를 iOS 기기에 전달
* **Windows·macOS·iOS 앱의 신호 수신 (위 중계 서버)**
  * Windows 앱과 macOS 앱은 실행 중에, iOS 앱은 화면에 열려 있는 동안 중계 서버와 연결을 유지해 신호를 받습니다. iOS 앱이 화면에 없을 때는 위 푸시로 받습니다.
  * 연결 항목: 위 해시 값만 사용합니다. 이메일이나 기기 식별자는 연결에 사용하지 않습니다.
  * 보관: 연결 정보는 연결이 유지되는 동안 중계 서버 메모리에만 있고, 연결이 끊기면 사라집니다. 연결 중에 Cloudflare가 네트워크 정보(IP 주소 등)를 처리할 수 있습니다.

### 4) 앱 업데이트 확인
앱 화면을 열 때, 지금 버전을 계속 지원하는지 확인하려고 LiTodo 웹사이트(`hoonest.net`, GitHub Pages)에서 모든 사용자에게 똑같은 공개 파일 하나를 받습니다.
* **전송 항목**: 없습니다. 요청에 계정, 기기 식별자, 할 일 내용을 담지 않습니다.
* **목적**: 더 이상 지원하지 않는 옛 버전이면 업데이트를 안내
* **보관**: 앱은 받은 최소 버전 값만 기기 안에 저장합니다. 요청을 처리하는 과정에서 GitHub가 네트워크 정보(IP 주소 등)를 처리할 수 있습니다.

### 5) 웹사이트 방문
LiTodo 웹사이트(`hoonest.net`, `litodo.hoonest.net`)는 회원가입, 입력 양식, 분석 도구, 광고를 두지 않습니다. 페이지를 전달하는 과정에서 호스팅 사업자(GitHub, Cloudflare)가 방문자의 네트워크 정보(IP 주소, 브라우저 정보 등)를 처리할 수 있습니다.

### 6) 문의·문제 신고 (선택)
사용자가 앱 설정의 [의견 보내기]나 직접 쓴 메일로 운영자에게 문의할 때만 처리합니다.
* **받는 항목**: 보내는 사람의 이메일 주소, 사용자가 쓴 내용. [문제 신고]를 고르면 앱이 만든 진단 파일이 메일에 첨부됩니다. 진단 파일에는 앱 버전, 기기 모델, OS 버전, 언어·시간대, 앱 설정값, 알림·배터리 사용 등 권한 상태, 남은 저장 공간, 동기화 상태와 오류 코드, 할 일·완료 항목 개수와 항목별 무작위 식별자·상태·시각(할 일 내용은 넣지 않습니다), 기기별 무작위 식별자, 계정 해시 값의 앞부분(여러 기기가 같은 계정에 연결됐는지 확인용), 같은 계정에 연결된 기기의 종류와 마지막 접속 시각, 기기 안 백업의 개수와 시각, 위 1)의 진단 기록, 앱이 남긴 충돌 정보가 들어갑니다. Android에서는 앱이 남긴 시스템 로그도 함께 넣습니다. 진단 파일에는 할 일 내용, 계정 이메일 원문, 로그인 정보를 넣지 않으며, 파일 경로 속 사용자 이름과 이메일 형태의 글자는 가립니다.
* **전송 방법**: 앱은 사용자의 메일 앱에 받는 사람·제목·본문·첨부를 채워 넘기기만 하며, 메일은 사용자가 메일 앱에서 직접 보냅니다. 보내기 전에 첨부 파일을 열어 확인하고 빼거나 고칠 수 있습니다. Windows에서는 진단 파일을 기기에 저장해 보여 주고, 사용자가 직접 첨부합니다.
* **목적**: 문의 답변, 문제 원인 확인과 수정
* **보관**: 운영자의 메일함(Gmail)에 보관합니다. `litodo@hoonest.net`으로 보낸 메일은 Cloudflare 이메일 라우팅을 거쳐 그 메일함으로 전달됩니다.

## 2. 처리 목적

처리하는 정보는 다음 목적으로만 이용합니다.
* 상시 알림, 홈 화면·잠금 화면·데스크톱 위젯, 메뉴 막대, 트레이, 컴팩트 바를 통한 할 일 표시
* 사용자가 요청한 여러 기기 간 Google Drive 동기화 및 백업
* 앱 설정값 유지
* 더 이상 지원하지 않는 옛 버전의 업데이트 안내
* 문의 답변과 사용자가 신고한 문제의 원인 확인·수정

## 6. 이용자의 권리와 행사 방법

이용자는 언제든 자신의 개인정보를 열람, 정정, 삭제하거나 처리 정지를 요구할 수 있습니다. LiTodo의 데이터는 이용자의 기기와 본인 Google Drive에만 있으므로 대부분 직접 처리할 수 있습니다.
* **열람·정정**: 앱의 할 일 목록과 완료 목록에서 확인하고 고칠 수 있습니다.
* **기기 데이터 삭제**: 할 일을 영구 삭제하면 목록에서는 바로 지워지고, 기기 안 백업에서는 보관 기간(보통 최대 1년, 작업 종류마다 가장 최근 백업은 새 백업으로 바뀔 때까지)이 지나면 지워집니다. 백업까지 모두 바로 지우려면 앱을 삭제하거나 앱 데이터를 초기화하세요(Windows는 `%LOCALAPPDATA%\LiTodo` 폴더를 지우세요).
* **처리 정지(동기화 해제)**: 앱의 [설정] → [Google 계정 연결 해제]로 언제든 동기화를 끌 수 있습니다. 해제해도 기기의 할 일은 유지되며, 해제 후에는 클라우드 동기화와 실시간 동기화 신호가 중단됩니다.
* **클라우드 데이터 삭제**: Google Drive 웹의 [설정] → [앱 관리]에서 LiTodo의 **숨겨진 앱 데이터 삭제**를 선택하면 Drive에 저장된 동기화 파일과 기기 접속 기록이 삭제됩니다.
* **Google 권한 철회**: [Google 계정 관리](https://myaccount.google.com/permissions) 페이지에서 언제든 LiTodo의 접근 권한을 취소할 수 있습니다.
* **문의 메일 삭제**: 보낸 문의·문제 신고 메일을 지우려면 아래 11번 연락처로 요청해 주세요. 바로 지웁니다.
* **요청**: 그 밖의 요청은 아래 11번 연락처로 보내 주시면 10일 이내에 답변합니다. 운영자는 이용자의 할 일이나 Drive 데이터에 접근할 수 없으므로, 그 데이터는 위 방법으로 직접 처리해 주셔야 합니다.

## 7. 개인정보의 안전성 확보 조치

* 모든 네트워크 전송은 HTTPS(TLS)로 암호화합니다.
* Google 권한은 앱 전용 폴더와 계정 이메일 확인으로 최소화하며, 사용자의 다른 Drive 파일에는 접근하지 않습니다.
* Google 로그인 정보는 운영체제가 제공하는 보안 저장소(키체인 등)나 앱 전용 폴더에만 보관하고, 백업으로 옮겨지지 않게 합니다.
* 이메일 원문은 운영자의 서버로 보내지 않으며, 동기화 신호에는 해시 값만 씁니다.
* 운영자의 서버에는 사용자의 할 일과 계정 정보를 저장하지 않습니다.
* 기기 안 진단 기록과 문제 신고용 진단 파일에는 할 일 내용, 계정 이메일, 인증 정보를 넣지 않고, 파일 경로 속 사용자 이름과 이메일 형태의 글자는 가립니다.
